Retail Demand Forecasting ML

Retail product-store demand differs in frequency and variability. The objective was to estimate daily sales quantities using differentiated models rather than a single universal predictor.

Calendarized sales input → data preparation and calendar features → ADI/CV² demand segmentation → specialized model training → grouped evaluation → serialized artifacts → batch inference and forward forecast outputs.

Data Intelligence Hub

Enterprise BI teams need to discover, understand and reuse assets before developing new reports. AI for BI targets engineering productivity rather than conversational business analytics.

Flask portal → workflow catalogue and run API → subprocess notebook runner → metadata extraction and documentation artifacts → integrated Metadata Explorer. A separate GCP metadata connector and OAuth integration extend the foundation.
